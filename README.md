# GITHUB Group Assignments

## Setup

1. Choose a group leader
2. The leader will **fork** the repo at: https://github.com/mattansb/git-group-assigment
3. The leader will invite you to their branch (Settings > Collaborators > Add people)
4. Each person will then **clone** the repo locally to your computer.

## The Task

Each group has a sub-folder.
Within that folder, you will find a list of facts in a `.md` file.

1. Make a new branch from `main`: `factcheck`
  - Work on the `factcheck` branch to correct the facts.
  - Work on the `main` branch to add some new facts.
  (the group leader will divide the work).
2. Make a pull request (PR) to merge `factcheck` _into_ `main`, review it, and merge.
3. The group leader will make a PR into *my* repo.

## Tips and Notes

Don't forget:

* `fetch` -> `commit` -> `push` -> ...
* Be careful of creating any conflicts! (resolve them if needed!)

**Screen sharing is not allowed during this exercise**

---

**EACH of the your teammates must make at least one commit to get full credit for this assignment.**

***Good luck!***
